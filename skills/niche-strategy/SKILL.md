# Niche strategy

Read [the editorial guide](references/editorial-guide.md). Use the latest choice the user supplied to enter the workflow. Complete one stage per response.

1. **Choose a niche.** With no niche or fixed idea, offer 10–12 niches. Give the audience appeal, three subniches, and an example title for each. Recommend three based on curiosity, visual potential, and available evidence. Ask for a niche and optionally a subniche.
2. **Choose an idea.** With a niche but no fixed idea, pitch exactly 10 distinct ideas with an accurate title, opening hook, central question or surprising fact, and visual concept. If only a broad niche was selected, vary its subniches. Ask for the chosen idea and target duration. If the user provides just one of those after receiving the ideas, ask only for the missing one.
3. **Write the voiceover.** With a fixed idea and a duration, verify the central claims and deliver one continuous narration paragraph. Put source notes and any timing caveat outside the paragraph. For revisions, retain the subject, duration, and format unless the user changes them.

If the user requests production from an approved script, hand the exact narration, source notes, chosen idea, duration, and any selected niche and subniche to [video-studio](../video-studio/SKILL.md). Leave format, renderer, and voice decisions to production intake.
